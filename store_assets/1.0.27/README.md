# Decide For Us 1.0.27 store assets

## Apple App Store

- Create App Store version `1.0.27` after build `42` finishes processing.
- Upload the three PNG files in `apple/iphone-6.3/` as the 6.3-inch iPhone screenshots, in filename order.
- Attach iOS build `1.0.27 (42)`.
- The 1024px icon is included in the binary; `app-icon-1024.png` is retained here as the release master.

## Google Play

- Upload Android App Bundle version code `42` to the intended testing or production track.
- In **Grow users > Store presence > Main store listing**, replace the store icon with `google-play/play-store-icon-512.png`.
- Capture Android screenshots separately before replacing the Play listing screenshots. The supplied images are iPhone captures and should be used for Apple only.

## Validation

- Apple screenshots: 1179 x 2556, opaque 24-bit PNG.
- Apple icon master: 1024 x 1024, opaque PNG.
- Google Play icon: 512 x 512, 32-bit PNG.
